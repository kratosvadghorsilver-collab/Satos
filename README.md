## Como publicar

1. Criar repositório no GitHub (ex: assedio-sexual-escolas)
2. Arrastar TODOS os ficheiros de uma vez
3. Settings → Pages → Deploy from branch → main → / (root)
4. Aguardar 1-2 minutos
